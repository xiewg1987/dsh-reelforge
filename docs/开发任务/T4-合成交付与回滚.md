# T4 · 合成交付与回滚

> **一句话目标**：把片段变成**一章一条的成片**并交到用户手上；出错时能退回去；缺东西时说清楚缺什么。
>
> **主文档出处**：§6.6（变更日志与回滚）· §9.1（ffmpeg 合成）· §9.2（交付物规范）· §9.3（降级矩阵）· §10.3（聊天行交付）
> **波次**：③ 可与 T5 并行　**依赖**：T3（要有片段）+ T2（要有资产）

---

## 1. 前置

- **依赖 T3**：`shots[].video_path` 已有值、章节的 `music_path` 已定、`enable_subtitles` / `enable_bgm` 开关已生效。
- **依赖 T2**：资产原件（角色参考图、变体、场景、道具、音色样本、BGM）已落盘，参考图包才有东西可打包。
- **本机 ffmpeg 未必存在**——这是**正常的**，不是阻塞项：缺 ffmpeg 时的降级路径本身就是本任务的交付内容之一（见 §2.3）。

## 2. 范围内

### 2.1 ffmpeg 合成（§9.1）

保留 `ffprobe` 探测 + `ffmpeg` 处理的双工具形态，链式参数原样透传，但**插件内部只暴露一层受控的 `assemble` 能力**给上层用。

**合成流程（按章节做，一章一条成片）**：

1. **探测**每个片段（分辨率、帧率、时长、音轨）→ 找出不一致项。
2. **归一**：统一到目标分辨率（9:16 → 1080×1920）、帧率、像素格式 `yuv420p`、采样率。
3. **拼接**：concat demuxer（片段参数已归一时）或 filter_complex（需转场 / 补帧时）。
4. **音轨**：H3 原生音轨 → 直接用；TTS 叠加 → 按分镜时间轴对齐；BGM → `amix` 混音 + `loudnorm` 归一化 + ducking。
5. **字幕**：按分镜台词 / 旁白生成 **SRT**，再按项目开关 `enable_subtitles` **烧录**一版；同时保留**不烧录**的一版。烧录时**自动去掉角色名前缀**（台词写的是「小夏：那一夜…」，成片字幕只显示「那一夜…」）。
6. **输出**：`H.264` + `AAC` / 24fps / `yuv420p` / `+faststart`（网页与移动端友好）。

### 2.2 交付物（§9.2）——**按章节组织，每章一套，路径带章节序号**

| 交付物 | 路径 | 说明 |
| --- | --- | --- |
| 成片（带字幕） | `exports/ch01_带字幕.mp4` | 字幕已烧录 |
| 成片（无字幕） | `exports/ch01.mp4` | 同一批片段**重封装，不重渲** |
| 字幕 | `exports/ch01.srt` | 时间轴由分镜时长推 |
| 分镜表 | `exports/ch01_分镜表.html` | 自包含单文件：镜号 / 景别 / 运镜 / 时长 / 画面描述 / 对白 / 旁白 + 每镜缩略图；可打印成 PDF |
| 分镜表（图） | `exports/ch01_分镜表.jpg` | 9×N 缩略图拼版，便于快速浏览 |
| 参考图包 | `exports/ch01_参考图包.zip` | 每镜参考图 + `project.json` 片段 + 每镜提示词 `.txt` + `manifest.json` |
| 资产原件 | `assets/` | 角色参考图、服装 / 年龄变体、场景图、道具图、音色样本、背景音乐 |
| 背景音乐库 | `assets/music/` | 可手工生成 / 预览 / 选择后**一次性应用到多个章节** |

**成片必须落盘，不只存链接**——远端链接会过期。

**交付到对话**：由 **T5** 统一注册聊天行视图（`src/host/chatEvents.js` + `conversation.chat.node` 插槽），本任务只负责**产出 payload 数据**（`src/core/deliverPayload.js` / `src/core/changelogPayload.js`）。**文件所有权与 payload 形状见 `T5-工作台与技能工厂.md` §2.4.4（F9）——不要改 `chatEvents.js`。**

### 2.3 降级矩阵（§9.3）——**7 种缺失，每一种都有明确说法**

| 缺失 | 成片 | 分镜表 | 参考图包 | 对话里怎么表述 |
| --- | --- | --- | --- | --- |
| 视频 provider 全挂 | ❌ | ✅ | ✅（含每镜视频提示词） | 「未生成视频：{原因}。已交付分镜与提示词，可在别处生成后回来合成」 |
| 图像 provider 挂 | ⚠️ 纯文字卡 | ✅ | ⚠️ 文字卡 | 「参考图不可用，已用文字卡占位」——**并说明视频阶段因此不可跑**（硬依赖） |
| **音色缺失** | ⚠️ 无参考音 | ✅ | ✅ | 「{角色} 的参考音不可用，该镜声音已缺失」——**不静默降质** |
| ffmpeg 挂 | ❌ | ✅ | ✅ | 「本机缺 ffmpeg，未能出成片；附拼接命令」 |
| 部分镜失败 | ⚠️ 占位帧 | ✅ | ⚠️ 标缺 | 「第 4、7 镜生成失败，已用占位帧占位」 |
| **显存不足** | ❌ | ✅ | ✅ | 「显存不足 8GB，本机跑不动视频阶段；已交付分镜与参考图」 |
| 模型通道不可达 | ❌ | ✅ | ❌ | 「模型通道不可达，本次只产出分镜」 |

**通用原则**：宁可交付「不完整但诚实」的结果并说清缺什么，也不要用占位物假装成功。**并且把「软依赖缺失」也要说出来**（音色缺失、参考音被截断）——upstream 那边是静默降质的，ReelForge 要在界面上**显式化**。

> 「降级」在界面上**不写「已完成」**——一律写「已用占位帧占位」「本机缺 ffmpeg，未能出成片」「音色缺失，静音成片」。

### 2.4 变更日志与三级回滚（§6.6）

对内容表（项目 / 章节 / 分镜 / 资产 / 参考图）的**每次增删改**留原始行快照。

| 能力 | 语义 |
| --- | --- |
| **单条回滚** | 恢复某一行的旧值 |
| **整批回滚** | 一次调用 = 一个 `batch_id`，整批回退 |
| **按时间点回滚** | 回退到某个时刻之前的所有变更 |
| **漂移保护** | 变更之后该行又被改过 → **409 拒绝**，`force: true` 才覆盖 |
| **硬约束** | **没有任何 API 用于删除项目**；回滚也拒绝回滚「项目创建」 |

**实现要点**：

- 快照存在**插件自有存储**（R2），**不塞会话日志**。
- **媒体二进制不随回滚删除**（磁盘上的图片 / 视频文件留下）——回滚只恢复数据库内容，**UI 必须说清这一点**，否则用户会以为文件也没了。
- **漂移保护是必需的，不是可选**：回滚会覆盖别人（模型或用户）在这之后的修改。
- 变更日志**随项目删除一并清除**，不自动清理——否则工作区会无限膨胀。

**`rollback` 是触发类工具**，走宿主 `ask` 人工授权（R4）。

### 2.5 章节制的一章一集

- 一章 = **一个可独立交付的成片单元**。
- BGM 可**一次性应用到多个章节**（`set_chapter_music`）。
- 播放器与交付物**都按章组织**（见画板 `10-RF/Player` / `11-RF/Deliver`）。

## 6. 关键契约速查

**输出规格**：`H.264` + `AAC` / `24fps` / `yuv420p` / `+faststart`。

## 7. 风险与已知坑

| # | 坑 | 后果 | 怎么躲 |
| --- | --- | --- | --- |
| 1 | 只交付带字幕的一版 | 用户要无字幕版时得重渲 | **无字幕版必须重封装，不重渲** |
| 2 | 字幕不剥角色名前缀 | 成片字幕出现「小夏：」 | 烧录前统一剥离 |
| 3 | 回滚连带删了媒体 | 视频图片找不回来，用户以为数据没了 | **只回滚内容，不删二进制**，且**明说** |
| 4 | 回滚不查漂移 | 静默覆盖模型/用户后来的修改 | **409 + force** |
| 5 | 降级写成「已完成」 | 用户以为出了完整片 | 一律写具体说法（占位帧 / 静音 / 未能出成片） |
| 6 | 音色缺失不吭声 | 声音没了但界面说「已完成」 | 软依赖缺失**必须说出来** |
| 7 | 缺 ffmpeg 时硬报错 | 用户拿不到任何东西 | 降级为「分镜表 + 参考图包 + 可执行拼接命令」 |
| 8 | 远端链接当交付物 | 链接过期，交付物失效 | **必须落盘** |
| 9 | 回滚「项目创建」 | 项目被删，等于绕过「无删除 API」 | 明确拒绝 |
| 10 | 变更日志不随项目清除 | 工作区无限膨胀 | 随项目删除一并清除 |
