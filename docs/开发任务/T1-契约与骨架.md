### 2.3 包名三处一致（F1，R7）

**这是全项目最阴的一条**：三处不一致 → client **半静默不加载**，控制台不报错，右栏就是没这个 Tab。

必须三处**完全相等**：
1. `package.json` 的 `name`
2. `cordis.patch.yml` Loader 行的 `name`
3. 构建产物里 `window.__ModuleLoader__.load({ id })` 的 `id`

**验证方式**：装上后用 `cordis_inspect_query` 确认 client 已注册；**并检查构建产物里的 id 字面量**——不要只看 `package.json` 就以为对了。

### 2.5 写入门禁（F3，§6.5）—— 第一优先级的工程决策

`src/host/gate.js`。**为什么比「校验」更重要**：外部写入若能改 `status`，就能**伪造「已生成」状态**，绕过渲染直接出成片；若能改 `seed`，则是「接口答应了、实际静默无效」——**接口答应了却没做到，比直接报错更坏**。

字段白名单（照抄 §6.5）：

| 层 | 内容字段（模型/外部可写） | 产物字段（**只有渲染阶段**可写） |
| --- | --- | --- |
| 分镜 | `chapter` `scene_name` `camera` `visual` `dialogue` `narration` `sub_shots` `resolution` `aspect_ratio` `video_prompt` / `character_ids` `scene_ids` `prop_ids` `costume_ids` `age_ids` `audio_ids` `references` / `idx` `duration` | `status` `error` `video_path` `video_prompt_used` `prompt_id` `seed` |
| 章节 | `title` `novel` `script` | `seq` `status` `music_path` `music_prompt` `music_prompt_used` |
| 项目 | `name` `novel` `idea` `style` `video_resolution` `video_aspect_ratio` `video_width` `video_height` `target_duration` `enable_bgm` `enable_subtitles` | `status` `context` |

**7 条实现要点**（§6.5 逐条对应，别漏）：

1. **工具参数封闭**——注册的工具 schema 里**只列内容字段**，产物字段根本不出现，模型传了也进不来。
2. **白名单外一律报错**，不静默丢弃。拼错 `titel` 要立刻可见。
3. **数组字段的元素必须是字符串**——`[{id:'x'}]` 被 `String()` 变成 `"[object Object]"`，下游会当「无效 id」**静默丢弃**还回 200。
4. **校验在写入口，不在渲染前**——否则「写入完全合法、却在几分钟后的渲染阶段才炸」，错误离写入点太远。
5. **跨字段校验按「真正落库的值」算**——「省略 duration + 长台词」必须用默认值（5 秒）算上限。
6. **只改依赖字段时才重算**——拿库里的旧值重算会把历史超速台词变成整行不可编辑。
7. **数字字段必须显式判名**——否则任何白名单里的数字字段走到兜底分支都会被按 `duration` 校验。

### 2.6 小说自动拆章（§6.2）

`src/core/splitChapters.js`，照抄 infinite-creation `splitNovelIntoChapters()` 的**判定顺序**：

1. 命中 ≥2 个章节标题 → **按标题切**；
2. 命中 <2 个但正文 ≤ `6000` 字 → **单章**；
3. 否则按 `6000` 字**均分**；
4. 重复标题追加「·(2)」消歧。

### 2.7 会话投影与物化（§6.7）

- `src/host/projection.js`：注册 `ctx.sessionProjections` 单元，**纯 fold**——把会话事件 fold 成项目状态。
- `project.json` 是投影的**物化导出**，三层：项目 / 章节 / 分镜。
- **不新增会话事件 `type`**（R2）：阶段进展靠已有的、宿主已知的事件类型承载。
- 插件私有数据（快照、任务历史）走**存储服务**。

### 2.8 工作区与路径（§11）

`src/host/workspace.js`：照 infinite-creation `resolveProjectPath()` 的**越界防护**——相对路径 `resolve` 之后**必须仍在项目目录内**，越界返回 `null`（不是报错、不是拼接）。这条防的是提示注入导致的任意文件读/删。

写文件用原子写；仅新建用 `exclusive`（`wx`），不「先查存在再覆盖」。

### 2.9 13 个工具的签名（F4）

**只定签名与 schema，实现留空**（返回「未实现」即可）。签名一旦定死，后面 4 个任务**只填实现，不改 id、不加参数**。

| 工具 | 作用 | 写入门禁 |
| --- | --- | --- |
| `reelforge.import_novel` | 导入小说 → 拆章 | 写项目内容字段 |
| `reelforge.set_storyboard` | 写分镜（整章批量或单镜） | **只收内容字段** |
| `reelforge.save_context` | 写 `bible`/`style`/`continuity` | 只收三键 |
| `reelforge.update_shot` | 改单镜内容 | 同上 |
| `reelforge.create_asset` / `update_asset` | 资产增改 | 产物字段（`image_path`/`voice_ref`）**不可写** |
| `reelforge.bind_asset` | 资产绑到分镜 | 只收 id 数组 |
| `reelforge.run_stage` | 跑一阶段（可指定章节） | **触发类，走 `ask`** |
| `reelforge.regenerate_shot` | 重生成单镜 | **触发类，走 `ask`** |
| `reelforge.assemble_chapter` | 合成某章成片 + 字幕 | **触发类，走 `ask`** |
| `reelforge.set_chapter_music` | 指定章节背景音乐 | 写内容字段 |
| `reelforge.rollback` | 回滚内容变更 | **触发类，走 `ask`** |
| `reelforge.update_plan` | 改执行路径：**kind × 运行位置** | 写方案不写产物，**不走 `ask`** |
| `skill` / `skill_reference` | 读技能正文与参考文件 | 只读 |

> `reelforge.update_plan` 于**实现阶段合流时**补入（见 `00-总览.md` §3.1 变更记录）：
> 「执行路径」是 **kind × 运行位置**两个正交维度（§8.1），对话内的 plan 行必须能在
> **不烧钱、不走 `ask`** 的前提下直接改这两维——12 个工具里没有任何一个能表达这件事。
> 它的入参只有 `{kind, position}` 两个枚举，取值分别来自 `GENERATION_KINDS` 与 `RUN_POSITIONS`（F8）。
>
> `reelforge.rollback` 的入参是**扁平**的 `{mode, entryId?, batchId?, at?, force?}`，
> `mode` 取 `single` / `batch` / `timepoint`（与 `ROLLBACK_MODES` 一致）——
> 与 T4 的回滚引擎、T5 的变更日志行两侧都对得上。

## 6. 关键契约速查

**F1 包名三处**：`package.json.name` = `cordis.patch.yml` Loader `name` = 构建产物 `load({id})` 的 `id`。
**F2 Tab kind** = `reelforge-workbench`（**一经发布不可改名**；`TAB_ID` 可改）。
**F3 写入门禁字段表**：见 §2.5。
**F4 工具 id**：见 §2.9。
**F5 `WorkflowSpec` 形状**：`{id, kind, name, description, sourceFile, roles, media?, outputs, prune?}`。
**F8 枚举唯一来源**：`src/core/constants.js`。

**单镜时长**：`1 … 15`s，默认 `5`s；对白 `5.5` 字/秒；每镜说话人 ≤ `2`；`idx` ≥1 且**章内唯一**。
**画幅**：8 种取值（见 §2.4）；**9:16 是成片画幅属性，不是 UI 比例**。
