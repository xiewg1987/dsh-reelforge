# 文件所有权清单（5 个任务并行时的唯一依据）

> **规则**：每个文件**只有一个主人**。别人要改，走「报告里提出接口需求」，不要直接改。
> 违反这一条 = 并行开发必打架。

## 共享基础（**已由主控落定，任何任务都不得改**）

| 文件 | 内容 |
| --- | --- |
| `package.json` | 包名、exports、`dsh.bundle.patch`、`dsh.client.inject`、files、scripts |
| `cordis.patch.yml` | insert 行（id / name / config）、Config 默认值 |
| `src/core/constants.js` | **唯一枚举来源**（F8）：资产分类、上下文三键、状态、kind、分辨率、画幅、时长、白名单、工具 id、Tab kind、匹配规则 |
| `locale/{en,zh}.json` | `meta.title` / `meta.description` + UI 文案（**T5 可增补，不得删既有键**） |
| `icon.svg` | 插件图标 |
| `scripts/check-package-identity.mjs` | R7 包名三处相等的机器校验 |

> 发现 `constants.js` 缺枚举 → **在报告里列出来**，由主控统一补。**不许在自己文件里再写一份**（F8）。

## 命名归属的一条判定规则

- 宿主专属逻辑（`ctx.*`、服务调用、注册）→ `src/host/`（或 `src/client/` 的客户端专属）
- 与宿主无关的纯逻辑 → `src/core/`，**必须有单测**
- 两边都不许渗透：`src/core/` 里不许出现 `ctx`，`src/host/` 里不许出现可单测的业务算法
