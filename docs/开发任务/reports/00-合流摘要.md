## 偏离项（主控合并）

1. **工具数 15**：F4 文案写 13 ReelForge + 2 技能只读；`verify:bundle` 计 15 个宿主工具注册项（含 skill / skill_reference）。
2. **客户端构建**：无 tsdown 分片，采用 `build-client.mjs` 单文件拼接（T5 任务书 R10 分片路线在本仓库以「无分片、确定性拼接」落地；验收 A34–A36 标记为 N/A，A38 以 pack dry-run 为准）。
3. **RF.actions 已加固，但最终 transport 仍待 owner 确认**：UI 写操作经 `remote.session.prompt` 转模型调工具（`src/client/entry.js`）。原先「没有 transport ⇒ 只 `console.warn`」是静默降质，现已改为**可见失败 + 可重放**（请求进 `RF.actions.pending` 队列并发结构化通知，文案说清缺什么、给什么替代；`retryPending()` 可一键重放）。代码里**不写死**任何宿主 API 名 —— 本机无 DSH 宿主包，无法证明 `remote.commands` 存在，那处探测带运行时存在性检查且非默认路径，启用前需宿主 owner 确认签名。
4. **本轮修掉的真实缺陷（都是新增测试/实跑暴露出来的，不是代码审查发现的）**：① `src/client/components.js` 的 `RF.ui` 早于 `RF.SectionLabel`/`RF.MetaRow` 建立 → 两槽位为 `undefined`，有数据时 `h(undefined)` 抛 "Element type is invalid"（章节/镜头/技能/输出 4 个页签 + progress 消息行）；② `src/host/workspace.js` 的 `writeFileAtomic` 失败时只把临时文件截空而非删除 → 每次写失败在工作区留隐藏 `.tmp` 垃圾文件；③ `src/host/tools.js` 调 `runStage` **不传 `deps`** → 探测直接踩 `deps.llm.ping()` 的 TypeError，4 个触发类工具必崩；④ 变更日志**从来没有被记录**（全仓无 `engine.record()` 调用）→ `rollback` 在真实流程里恒 404；⑤ `src/host/changelogStore.js` 章节行带 `shots: undefined` → JSONL 往返丢键 → **章节层回滚 100% 误报漂移 409**，整层不可用；⑥ 变更日志条目 id 重启后从 `cl_000001` 重新计数 → **撞号**，single 模式按 id 回滚会退错变更；⑦ `list(projectId)` 忽略 projectId（跨项目串数据）+ `clearProject` 清空整个日志文件（误删其它项目历史）；⑧ `src/media/assemble.js` 的 concat 清单写工作区相对路径，但 ffmpeg 按**清单目录**解析 → **生产拼接必失败**；⑨ 调 ffmpeg 从不传 cwd → 成片落在**宿主进程 cwd**、不在会话工作区（`assemble.js` 与 `deliver.js` 两处）；⑩ `planAudioMix` 只有 `-map [aout]` 没有 `-map 0:v` → 带 TTS/BGM 的一章**产出纯音频却报 ok:true**（静默损坏）；⑪ `planContactSheet` 用 ffmpeg 不认的 `color=#222`、且 `tile` 被喂 N 个输入 → **拼版图永远出不来**；⑫ `planContactSheet` 的 `concat` 各输入 SAR 不一致（`scale` 各自补偿比例）→ "Error reinitializing filters!"，需补 `setsar=1`；⑬ `src/host/stageBridge.js` 走自己的四字段载荷，**从不调用 runner** → 通道收到的 `payload.prompt` 是 `undefined`；同时 `runStage` 固定传 `state.completed = {}` → **video 阶段经桥永远被硬依赖拒掉**、指纹幂等跨不过桥。
5. **ffmpeg 实机**：本机既没有 PATH 上的 ffmpeg，也没有设 `RF_FFMPEG_PATH`；T4 A1–A3 的实跑组会**显式 skip**（`src/media/__tests__/assemble-e2e.test.js` 的「真 ffmpeg 实跑」组）。装好 ffmpeg 后设 `RF_FFMPEG_PATH`（以及 `RF_FFPROBE_PATH`）即可解锁；缺 ffmpeg 时的降级话术由 `src/media/__tests__/ffmpeg.test.js`、`degrade.test.js` 与 `assemble-regress.test.js` 覆盖。
