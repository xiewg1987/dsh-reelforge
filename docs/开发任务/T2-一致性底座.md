## 2. 范围内

### 2.1 上下文三键（§6.3、§7.4）

`src/core/consistency.js`。**只有三个键**：`bible` / `style` / `continuity`。多写一个键 → **报错**，不静默丢弃。

| 键 | 落点 | 写入语义 | 关键约束 |
| --- | --- | --- | --- |
| `bible` | `context/bible.md` | **整段覆盖** | **必须含「场景站位表」章节**：空间锚点 + 角色默认方位 + 道具锚点 + 180° 轴线与允许机位。写入时**先读回再合并**，**不得覆盖已有人物与衣橱** |
| `style` | `context/style.md` | **整段覆盖** | 统一画风 / 光线 / 色调；可声明全片禁止项 |
| `continuity` | `context/continuity.json` | **追加** `{t, content}` 数组 | **只追加，不覆盖**；按时间点注入 |

**注入标题固定**（生成时拼进提示词，标题不能自创）：

- `【人物圣经（一致性锚点，后续所有生成必须遵守）】`
- `【风格指南（统一画风/光线/色调）】`
- `【连续性记录】`

> **代码层无 schema**——这是 upstream 的真实形态：结构约定在**技能正文与 systemPrompt 层**，不在代码里写死一套 JSON Schema。照抄，别自创。

### 2.2 10 类资产与变体（§6.4）

`src/core/assets.js`（或并入 `consistency.js`）。

- 10 类：`character` `scene` `prop` `costume` `age` `voice` `music` `sfx` `video` `other`。
- **`costume` / `age` 是变体类**，必须带 `parent_id` 指向角色；缺 `parent_id` → **拒绝写入**。理由：否则会「素材库里看得见、分镜能引用、生成时被静默忽略」。
- 资产的**产物字段**（`image_path` / `voice_ref`）**只能由生成阶段写**（F3），外部写入报错。

### 2.3 参考素材装配（§7.4）——**本任务的核心交付**

**这是 infinite-creation 最值钱的一段逻辑**，它决定「同一角色在不同镜头里是不是同一个人」。

**装配顺序（不可改）**：

```text
人物图 → 场景图 → 道具图 → 人物语音
```

**角色参考图优先级（独立维度，不叠加）**：

```text
服装 > 年龄变体 > 角色原图
```

即：指定了服装就取服装图（不叠角色原图）；只指定年龄就取年龄变体；都没有才取角色原图。

**标签格式**：

| 对象 | 标签 |
| --- | --- |
| 角色（有服装） | `角色名（服装名）` |
| 角色（无变体） | `角色名（人物形象）` |
| 场景 | `场景名（场景背景）` |
| 道具 | `道具名（道具）` |

**硬约束**：

- **只有说话角色才引用音色**——不出声的角色的音色不进参考素材。
- 参考图 **≤ 9**，音视频 **≤ 3**。超限**报错**，不静默截断。
- 说话人匹配必须**规范化后精确相等**（`nameMatches`：`normalizeName` 之后比较，**禁用 `includes`**）。
- **未匹配的说话人只 warn，不报错**——可能是有意的旁白。
- 名称识别用 `textMentions`，要**排除被更长名字覆盖**的短名（"林岸"与"林岸生"同框时不能都命中）。

**`resolveRefs()` 冻结形状（F6）**：

```text
resolveRefs(shot, assets, ctx) → {
  images:  [{ assetId, kind, path, label, refIndex }],   // 已按装配顺序排好
  audios:  [{ assetId, kind, path, label, refIndex }],
  tags:    ["林岸（雨衣）", "码头栈桥（场景背景）"],
  order:   ["character", "scene", "prop", "voice"],
  warnings:[ ... ]                                          // 未匹配说话人等，只 warn 的项
}
```

### 2.4 参考标签与提示词占位符（§7.4）

- 参考素材在提示词里用**占位符**引用：`__MINIMAX_H3_REF_N__`，**N 从 1 起**。
- 校验正则：`/__MINIMAX_H3_REF_\d+__/g`。
- **提示词改写最多 2 次尝试**（§8.4 约束），且**必须保留全部占位符**——丢一个占位符等于引用素材丢失。
- `src/core/promptBuilder.js`：提示词装配 + 参考标签。

### 2.5 时长量化（§7.2，纯算法部分）

`src/core/quantize.js`，**纯函数**，允许时长集合 `D` 由调用方传入（T3 按规格给 D）：

```text
quantizeDurations(shots, D, targetDuration) → [{ idx, before, after, changed }]
```

规则（照 §7.2）：

1. 取允许时长集合 `D`（H3 → `[1..15]` 整数秒）。
2. 每镜理想时长**投影到 D 上取最近值**。
3. **带约束的分配**：先按权重分配理想时长，再逐镜就近取整，**用差额在多镜之间做守恒调整**（保证总和精确命中 `target_duration`）。
4. 量化后某镜 > 上限 → **拆镜**；< 下限 → **并镜**。
5. 结果**写回 `shots[].duration`**，并在 `provenance.authorAdded` 记一笔「时长已按后端约束调整为 4/4/4/5/5/4/4（合计 30）」。

> 这条是「分镜本身按后端能力塑形」——**不是选完模型再祈祷分镜能用**。

### 2.6 技能引擎（§8.2）

`src/skills/{scan,route,skillTools}.js`。

**frontmatter 契约**：

- 分隔符正则：`/^---\s*\n([\s\S]*?)\n---\s*\n?/`。
- ⚠️ **只识别单行标量**——多行写法（`description: >` 折行）会**失配**，整块被当正文。
- `name` 事实上必填（目录名兜底、**不报错**）；`description` **空串会让路由与目录双双失效**——当非法技能处理。
- `whenToUse` / `version` 可选。
- **`SKILL.cn.md` 优先于 `SKILL.md`**。

**技能名安全校验**：拒绝 `/` `\` `:`、绝对路径、`.`、`..`。

**两个只读工具**：

| 工具 | 行为 |
| --- | --- |
| `skill(name)` | 返回 **XML 包裹** + 参考文件索引（文件名 / 字数 / **前 160 字预览**） |
| `skill_reference(name, ref)` | 按**文件名精确匹配**，**仅 `.md` / `.txt`** |

两者**均截断 120000 字符**。

**来源判定**：`source = name === 'novel-to-video' ? 'bundled' : 'installed'`（自有技能 `generated` 由 T5 产出）。

**路由——刻意不做关键词路由表**：

> upstream 有 22 条 `KEYWORD_ROUTES` 正则，但**`routeSkill()` 在生产路径中根本没被调用**——实际靠 systemPrompt 里的映射 + LLM 自主 `skill(name)`。
> 照抄那 22 条正则 = 抄一套长期漂移、且本来就没在跑的代码。**ReelForge 不做关键词路由表**，靠 systemPrompt 映射 + 模型自主调用 + **`novel-to-video` 无条件注入兜底**。

## 7. 风险与已知坑

| # | 坑 | 后果 | 怎么躲 |
| --- | --- | --- | --- |
| 1 | **T3 自己写了一套参考装配** | 同一镜在两处得到不同参考图，一致性静默崩掉 | F6 冻结 + T3 只消费 |

| 4 | 所有角色都塞音色 | 音轨被无关系的音色占满，上限 3 被浪费 | **只有说话角色**才引用音色 |
| 5 | `bible` 覆盖式写入 | 已写的人物设定被抹掉 | 先读回再合并 |
| 6 | `continuity` 覆盖式写入 | 历史连续性记录丢失 | **只追加** |
| 7 | 变体资产不校验 `parent_id` | 素材看得见、引用得到、**生成时被静默忽略** | 写入口拒绝 |
| 8 | 提示词改写丢了占位符 | 参考素材静默丢失，画风漂 | 改写 ≤2 次 + 每次后校验占位符齐全 |
| 9 | 抄了 22 条关键词路由正则 | 抄了一套上游**根本没在跑**的代码，还要长期维护 | 不做路由表；systemPrompt + 兜底注入 |

| 11 | 搬上游 `skills/` 正文 | **许可越界**（`skills/` 与 `vendor/` 不在 MIT 覆盖范围） | 正文自有，只兼容格式 |
