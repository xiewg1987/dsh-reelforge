# 音色描述模板

把下面这张表填完，就是一条可用的音色描述。**填不出来的项不要编**——留空比编造好。

## 一、模板

```text
{角色名}，{性别}{年龄}，{音高与音量}，{音色质地}，{语速与节奏}，{口音}，{情绪基线}
```

示例：

```text
林岸，28岁男性，中低音，音量偏低，带轻微沙哑与海风磨出的颗粒感，语速慢，句尾略沉，轻微南方口音，情绪克制不外放
```

## 二、逐项怎么写

| 项 | 写法 | 反例 |
| --- | --- | --- |
| 性别与年龄 | `中年男性，五十上下` / `年轻女性，二十出头` | `成熟` |
| 音高与音量 | `中低音，音量偏低` / `偏高音，气息足` | `有磁性` |
| 音色质地 | `沙哑、带颗粒感` / `清亮、略带鼻音` | `醇厚` |
| 语速与节奏 | `语速慢，句尾下沉` / `语速快，尾音上扬` | `节奏感强` |
| 口音 | `轻微南方口音` / `无明显口音` | — |
| 情绪基线 | `克制不外放` / `外放、爱笑` | `有故事感` |

**判断标准**：这一项能不能翻译成声学特征。不能的，就是空词。

## 三、群体区分

同一批角色的音色要**互相拉开**，否则观众分不清谁在说话：

- 音高拉开：一个高、一个低。
- 语速拉开：一个慢、一个快。
- 质地拉开：一个沙哑、一个清亮。
- 口音最多用一两个，别给每个人都加口音。

## 四、和人物圣经对齐

| bible 里的设定 | 音色描述里对应写 |
| --- | --- |
| 「声音低沉」 | `中低音` |
| 「语速慢」 | `语速慢` |
| 「带南方口音」 | `轻微南方口音` |
| 「一贯克制」 | `情绪克制不外放` |

两边冲突 → 以 `bible` 为准（bible 是锚点）。

## 五、bible 没写声音时

按角色的**年龄 / 性别 / 身份**做保守推断，例：

- 老年男性 → `中低音，音量偏低，语速慢`
- 少年 → `偏高音，语速偏快，音色清亮`

推断出来的是**基线**，不是最终音色——推断不出就**跳过并在对话里说明**，
不要硬编一个搭不上的声音。

## 六、常见错误

| 错误 | 后果 |
| --- | --- |
| 描述只写情绪不写声学 | 模型自由发挥，每次生成都不一样 |
| 两个角色描述雷同 | 观众分不清谁在说话 |
| 描述里有占位符没替换 | 生成出「{性别}{年龄}」这种垃圾音色 |
| 一次写 5 个维度但只填 2 个 | 其余维度随机，长得都不像 |
