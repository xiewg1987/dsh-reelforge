# 音色设计规范

## 一、音色是独立阶段

音色属于 `tts` 阶段，**在 `video` 之前**。不要在写分镜时"顺便"假定音色。

- 产出：每个角色的 `voice_ref`（音频样本路径）。
- `voice` 类资产也可以单独建，但**必须能关联到角色**（`parent_id` 指向角色）。

## 二、音色描述怎么写

用**可听见的特征**写，不要用性格形容词堆砌：

| 维度 | 例子 |
| --- | --- |
| 性别与年龄 | 中年男性，五十上下 |
| 音高与音量 | 中低音，音量偏低 |
| 音色质地 | 沙哑、带颗粒感，像久经风霜 |
| 语速与节奏 | 语速慢，句尾下沉 |
| 口音 | 轻微南方口音 |
| 情绪基线 | 克制、不外放 |

反例：「富有磁性」「充满故事感」——这些模型无法落到声学特征。

填写模板（逐项对照 + 反例 + 常见错误）见 `references/voice-description-template.md`。

写法示例（存进资产的 `description`）：

```
林岸，28岁男性，中低音，音量偏低，带轻微沙哑与海风磨出的颗粒感，
语速慢，句尾略沉，轻微南方口音，情绪克制不外放
```

## 三、从人物圣经继承

音色描述的**依据是 `bible` 里角色的声音设定**。两边必须一致：

- bible 写「低沉、沙哑」→ 音色描述也写低沉沙哑。
- bible 没写声音 → 音色描述从角色的年龄/性别/身份推断，**推断不出就跳过并说明**，
  不要硬编一个。

## 四、绑定

1. 建 `voice` 资产（`reelforge.create_asset`），`category: 'voice'`，带上音色描述。
2. 绑定到角色：`parent_id` = 角色 id。
3. 角色的 `voice_ref` 由**渲染阶段**写入——内容写入会被门禁拒绝，这是对的。

## 五、只有说话角色才引用音色

装配参考素材时，**只有本镜有台词的角色**才提交其音色。

- 不出声角色的音色不进参考素材（否则 3 段音频名额被占满）。
- 某镜说话人超过 **2 个** → 先拆镜，不要靠多挂音色解决。

## 六、音视频上限

- 参考**音视频 ≤ 3**（与参考图 ≤ 9 是两回事）。
- 超限**报错**，不静默截断。撞上限时的处理顺序：
  1. 先去掉没有台词的角色的音色；
  2. 再确认本镜说话人 ≤ 2；
  3. 再考虑拆镜。

## 七、缺音色时怎么说

`tts` 是 `video` 的**软依赖**——缺了也能出片，但会降质。

必须**在对话里明说**，不要让用户拿到成片才发现没声：

> 「林岸的音色没生成出来，这一镜出片没有他的声音。我可以先补跑 `tts` 阶段再重跑这一镜，
> 要现在补吗？」

**不许静默出烂音色**——宁可跳过并在对话里点名，也不要拿一个不搭的声音糊过去。

## 八、和提示词的关系

音色的参考标签是 `角色名（音色）`，占位符 `__MINIMAX_H3_REF_N__`，
编号排在人物图 / 场景图 / 道具图之后。详见 `reelforge-video-prompt`。
