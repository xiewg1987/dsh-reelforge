# 视频提示词 + 参考标签规范

## 一、一镜的视频提示词结构

按这个顺序写，缺哪块删哪块，但**主体与动作必须在最前面**：

```
[镜头与光位] + [主体与外观锚点] + [动作] + [环境] + [氛围与画质]
```

示例：

```
固定机位，中景，侧面平视；__MINIMAX_H3_REF_1__林岸（油布雨衣）
背对镜头站在栈桥东侧，右手扶栏杆，海风把雨衣下摆吹起；
__MINIMAX_H3_REF_2__码头栈桥（场景背景）江面灰雾，雨丝斜落；
__MINIMAX_H3_REF_3__黑伞（道具）伞面朝下滴水；
阴天散射光，低饱和冷调，写实电影感，35mm 胶片颗粒
```

要点：

- **动作要可拍**：一个镜头一个主动作。写「他转过身」，不要写「他犹豫、思考、然后猛地转身」。
- **时间在镜头内推进**用 `sub_shots` 描述，不要在提示词里写「然后…接着…最后…」。
- 人物外观**只写锚点**，细节交给参考图；重复写全套外貌会被模型重新解释，反而漂。
- **不要在资产参考图提示词里写镜头运动**——参考图是静帧。

## 二、参考素材怎么挂

### 装配顺序（不可改）

```text
人物图 → 场景图 → 道具图 → 人物语音
```

### 占位符

- `__MINIMAX_H3_REF_N__`，**N 从 1 起**，**紧跟中文标签文本**。
- N = 该参考在装配数组里的序号，**严格对应**。
- 标签格式：`角色名（服装名）` / `角色名（人物形象）` / `场景名（场景背景）` / `道具名（道具）` / `角色名（音色）`。

详见 `references/ref-tag-rules.md`。

### 上限

- 参考图 **≤ 9**，音视频 **≤ 3**。超限**报错**，不会静默截断。

### 只有说话角色才引用音色

不出声的角色，其音色**不进参考素材**——否则 3 段音频名额会被不相干的人占满。

## 三、改写纪律（最容易出错的一步）

提示词被改写（润色、扩写、翻译成英文）时：

1. **最多 2 次尝试**。
2. **每次改写后必须校验：原提示词里出现过的每个 `__MINIMAX_H3_REF_N__` 都还在。**
3. 少了占位符 → **回到原文重来**（不要在丢了占位符的版本上继续改）。
4. 连续 2 次都丢 → **放弃改写，用原提示词**。

> 丢一个占位符 = 那份参考素材（角色身份 / 场景 / 道具 / 音色）**静默消失**，
> 模型会自行发挥 → 角色换脸、场景漂移、道具消失。**这是静默降质，必须拦住。**

## 四、和上下文的关系

生成时上下文按固定标题注入，标题不能自创：

- `【人物圣经（一致性锚点，后续所有生成必须遵守）】`
- `【风格指南（统一画风/光线/色调）】`
- `【连续性记录】`

写提示词时：

- **人物圣经里的外观/配色是硬约束**——和它冲突的描述一律不要写。
- **风格指南是硬约束**——画风、光线、色调不要在单镜提示词里另起一套。
- **连续性记录决定当前状态**（比如「黑伞仍在缆绳桩上」），提示词要与之相符。

## 五、时长与说话人

- 单镜 **1–15 秒**；台词 **≤ 5.5 字/秒**；每镜说话人 **≤ 2**。
- 时长由量化统一处理，**不要靠提示词或 duration 凑总量**。
