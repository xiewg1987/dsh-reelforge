# 参考标签规范（`__MINIMAX_H3_REF_N__`）

## 一、占位符

- 格式：`__MINIMAX_H3_REF_N__`，**N 从 1 起**。
- 校验正则：`/__MINIMAX_H3_REF_\d+__/g`。
- **N 严格等于参考素材在装配数组里的序号**（从 1 数）。
  序号错了就是挂错参考图——图还是那张图，但模型以为它是另一个人。

## 二、装配顺序（不可改）

```text
人物图 → 场景图 → 道具图 → 人物语音
```

占位符按这个顺序连续编号。所以：

| N | 放什么 |
| --- | --- |
| 1..k | 人物图（按角色出场顺序） |
| k+1..m | 场景图 |
| m+1..n | 道具图 |
| n+1.. | 人物语音（**只有说话角色**） |

## 三、标签文本

占位符**紧跟中文标签文本**，标签告诉模型这张参考是什么：

| 对象 | 标签 |
| --- | --- |
| 角色（有服装变体） | `角色名（服装名）` |
| 角色（无变体，或用年龄变体） | `角色名（人物形象）` |
| 场景 | `场景名（场景背景）` |
| 道具 | `道具名（道具）` |
| 角色音色 | `角色名（音色）` |

写法示例：

```
__MINIMAX_H3_REF_1__林岸（油布雨衣）
__MINIMAX_H3_REF_2__码头栈桥（场景背景）
__MINIMAX_H3_REF_3__黑伞（道具）
__MINIMAX_H3_REF_4__林岸（音色）
```

**标签里的名字必须与资产库里的名字一致**——标签是给模型看的，名字对不上等于挂错。

## 四、角色参考图的优先级

```text
服装 > 年龄变体 > 角色原图
```

- 指定了服装就取**服装图**（**不叠角色原图**）。
- 只指定了年龄就取**年龄变体图**。
- 都没有才取**角色原图**。
- 服装与年龄是**两个独立维度，不叠加**：同时指定时取服装。

## 五、上限

| 类型 | 上限 |
| --- | --- |
| 参考图 | **9** |
| 音视频 | **3** |

超限会**报错**，不会悄悄截断。撞上限时的处理顺序：

1. 先去掉**没有台词的角色**的音色（只有说话角色才引用音色）。
2. 再合并**同场景重复的道具**引用。
3. 再考虑**拆镜**（把人物多的镜拆成两镜）。

## 六、改写纪律

提示词被改写（润色、扩写、翻译）时：

- **最多 2 次尝试**。
- **必须保留全部占位符**——少一个就等于那份额外参考素材丢失，画风立刻漂。
- 校验方法：原提示词里出现过的每个占位符，改写后必须还在。
- 连续 2 次都丢了占位符 → **放弃这次改写**，用原提示词。

## 七、角色名匹配

- 说话人匹配用**规范化后精确相等**（去空白、转小写），**不能用「包含」**。
  「林岸」会命中「林岸生」→ 错挂他人音色，还可能挤掉 3 段音频名额。
- 在场角色识别用「文本提及」，要**排除被更长名字覆盖的短名**：
  正文里出现「林岸生」时，「林岸」不应同时命中。
