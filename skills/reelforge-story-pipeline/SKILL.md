# 小说 → 剧本 → 分镜

## 一、拆章

`reelforge.import_novel` 负责导入与自动拆章。判定顺序（宿主已实现，不要另写一套）：

1. 文本里识别到 **≥2 个章节标题**（行首的「第 N 章/节/回/卷/集/部/篇」或 `chapter N`）→ 按标题切分。
2. 否则全文 **≤ 6000 字** → 单章，标题固定「第1章」。
3. 否则按 **6000 字均分** → 「第1章…第N章」。

**标题必须唯一**：重复标题追加「·(2)」等后缀——分镜按标题归属章节，标题撞车会让同一批分镜落进两个章节。

## 二、写人物圣经（`reelforge.save_context`，键 `bible`）

### 必含「场景站位表」章节

缺这一节**会直接报错**。必须写清四项：

| 项 | 写什么 |
| --- | --- |
| 空间锚点 | 场景里哪些位置是固定参照（门、窗、栏杆、台阶朝向……） |
| 角色默认方位 | 每个角色默认站在哪一侧、面向哪边 |
| 道具锚点 | 关键道具固定在哪个位置 |
| 180° 轴线与允许机位 | 轴线沿哪条线走，允许在轴线哪一侧架机 |

站位表是跨镜一致性的地基：它决定了第 3 镜和第 7 镜能不能看出是同一个空间。

### 已有人物与衣橱不能覆盖

写入是「整段覆盖 + 合并保护」：**每次写之前先读回现有 bible**，
把已有的人物与衣橱**一并带上**，再更新站位表。

推荐结构（合并逻辑按章节标题识别）：

```markdown
# 人物圣经

## 人物

### 林岸
- 外貌：28 岁男性，寸头，左眉有一道旧疤
- 配色：灰蓝工装
- 声音：低沉，语速慢

### 小夏
- 外貌：22 岁女性，黑色短发
- 配色：米白风衣

## 衣橱

- 林岸：洗旧衬衫、深灰工装裤、油布雨衣
- 小夏：米白风衣、帆布包

## 场景站位表

### 码头栈桥
- 空间锚点：栈桥向北伸入江面，北端是缆绳桩，南端是货仓门
- 角色默认方位：林岸常在栈桥东侧，小夏常在西侧靠栏杆
- 道具锚点：黑伞固定在缆绳桩上
- 180° 轴线与允许机位：轴线沿栈桥走向；允许机位在岸侧（东）与江侧（西），不得越轴
```

### 每个角色要有唯一外貌

「唯一」是关键：两处描述不能互相冲突（不能一处说寸头一处说长发）。
统一外貌 + 配色 + 声音三项，颜色词尽量复用固定几个。

## 三、写风格指南（`reelforge.save_context`，键 `style`）

整段覆盖。至少覆盖：**画风 / 光线 / 色调 / 镜头语言**，可以再加全片禁止项。

```
画风：写实电影感，浅景深，35mm 胶片颗粒
光线：阴天散射光为主，夜戏用单一暖色实用光源
色调：低饱和冷调，暗部偏青
镜头语言：缓慢推拉，手持轻微晃动，避免快速摇移
禁止：不要动漫风、不要塑料皮肤、不要文字水印
```

## 四、拆分镜（`reelforge.set_storyboard`）

- 一章一批写入；单镜微调用 `reelforge.update_shot`。
- **只能写内容字段**，产物字段（`status` / `video_path` / `seed` …）传了也进不来。
- 数组字段的元素必须是字符串 id：`["a_lin"]`，不要传对象。
- 每镜必填：`chapter` `idx` `scene_name` `visual` `duration`，有台词才写 `dialogue`。
- 资产绑定：先有资产 id 再绑（`character_ids` / `scene_ids` / `prop_ids` /
  `costume_ids` / `age_ids` / `audio_ids`）。

### 长镜头聚合

同一空间、同一主体、连续动作**不拆镜**，用 `sub_shots` 写镜头内的时间轴切分；
空间跳变或视角主体变化才拆。详见 `references/storyboard-fields.md`。

### 硬约束

- `duration` 1–15 秒；台词 ≤ **5.5 字/秒**；每镜说话人 **≤ 2**。
- 说话人名字必须与资产库里的角色名**完全一致**（规范化后精确相等）。

## 五、连续性记录（`reelforge.save_context`，键 `continuity`）

**只追加，不覆盖**。每章结束记一条断点：

```
第 3 章结束：林岸上了货船，小夏留在栈桥，黑伞仍在缆绳桩上
```

记录的是**下一章要用到的状态**，不是剧情摘要。
