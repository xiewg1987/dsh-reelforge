# 分镜写作规范（小说 → 剧本 → 分镜）

## 一、分镜字段（能写的只有这些）

内容字段（可写）：

`chapter` `scene_name` `camera` `visual` `dialogue` `narration` `sub_shots`
`resolution` `aspect_ratio` `video_prompt` `image_prompt`
`character_ids` `scene_ids` `prop_ids` `costume_ids` `age_ids` `audio_ids` `references`
`idx` `duration`

产物字段（**只有渲染阶段能写**，外部写入会被门禁拒绝）：
`status` `error` `video_path` `video_prompt_used` `prompt_id` `seed`

> 白名单外的字段一律报错，不静默丢弃。拼错字段名（如 `titel`）会立刻可见——
> 这正是设计目的，不要绕。

## 二、硬约束

| 约束 | 值 | 违反的后果 |
| --- | --- | --- |
| `chapter` | 不能为空，必须指向真实章节标题 | 分镜从章节视图与统计里消失，却仍被整片导出 |
| `idx` | 章内唯一，从 1 起 | 排序不确定（排序键 = 章节 seq → 章内 idx） |
| `duration` | 1–15 秒 | 后端不认 |
| 台词速度 | 字数 ÷ duration ≤ **5.5 字/秒** | 说不完，音频被截 |
| 每镜说话人 | **≤ 2** | 多人抢镜，音频名额被挤掉 |
| `resolution` / `aspect_ratio` | 落在枚举内，或空串表示继承项目设置 | 非法档位 |

## 三、长镜头聚合

一个小说段落常常对应多个镜头。按**动作与情绪的切换点**拆，不要按句子拆：

- 空间跳变（从一个地点到另一个地点）→ 必须拆。
- 视角主体变化 → 拆。
- 情绪转折点 → 考虑拆。
- 同一空间、同一主体、连续动作 → **不拆**，用 `sub_shots` 写镜头内的时间轴切分。

## 四、对白的写法

- 一行一个说话人：`林岸：上船。`（`名字：台词`）。
- 说话人名字必须与**资产库里的角色名一致**——匹配是规范化后精确相等，
  「林岸」不会命中「林岸生」，反过来写错也不会蒙对。
- 旁白单独成行：`旁白：那一年冬天。`。
- 每镜最多两个说话人；超了拆镜。

## 五、时长量化

分镜写完、生成之前，宿主会跑一遍时长量化，把每镜理想时长投影到后端允许的时长集合上，
并做守恒调整（总量不变），超上限拆镜、低于下限并镜。

所以**不要靠调 duration 去凑总量**——写了也会被量化覆盖。真正该改的是镜头数量。

## 六、provenance

`provenance` 分三段，交付时要区分：

- `userGiven` —— 用户原始设定，**不可被改写**。
- `authorAdded` —— 创作补充，每条可追责（时长量化会在这里记一笔）。
- `pendingConfirm` —— 待确认项，**在对话里主动问用户**。

模型不能把猜测写成既定事实——不确定的写进 `pendingConfirm`。
