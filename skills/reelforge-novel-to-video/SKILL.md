# ReelForge 总流水线（当前工作模式技能）

本技能是**兜底**：任何 ReelForge 任务，先按本技能判断处在流水线的哪一步，再决定调用哪个专项技能。
不要凭关键词猜——看**当前状态缺什么**，缺什么补什么。

## 一、四阶段（固定顺序串行，不得乱序）

| 阶段 | 做什么 | 产出 |
| --- | --- | --- |
| `llm` | 文本创作：写人物圣经/风格、拆章、拆分镜、写提示词 | `bible` / `style` / 分镜 / prompt |
| `image` | 资产生图：人物、场景、道具，以及服装/年龄变体 | 各资产的 `image_path` |
| `tts` | 音色设计：人物音色样本 | 各角色的 `voice_ref` |
| `video` | 逐镜出片并合成 | 分镜视频、成片 |

**依赖语义**（硬规则）：

- `video` **硬依赖 `image`**——没有参考图就直接报错，不要「先跑起来再说」。
- `video` **软依赖 `tts`**——音色缺失会降质，但**必须在对话里说出来**，不许静默出烂音色。
- `llm` 与渲染阶段互斥：先把文本创作做完，再进渲染。

## 二、上下文三键（生成前必须齐）

| 键 | 落点 | 写入语义 | 硬要求 |
| --- | --- | --- | --- |
| `bible` | `context/bible.md` | 整段覆盖 + **先读回再合并** | **必须含「场景站位表」章节**；**不得覆盖已有人物与衣橱** |
| `style` | `context/style.md` | 整段覆盖 | 统一画风/光线/色调，可写全片禁止项 |
| `continuity` | `context/continuity.json` | **只追加** `{t, content}` | 历史记录不得覆盖 |

**上下文只有这三个键**，多写一个键会直接报错——不要自创第四个键。

生成时注入的标题固定三个，不要自创标题：

- `【人物圣经（一致性锚点，后续所有生成必须遵守）】`
- `【风格指南（统一画风/光线/色调）】`
- `【连续性记录】`

## 三、流水线各步怎么做

1. **导入**：`reelforge.import_novel` 导入小说并自动拆章（一章一个独立分镜集）。
2. **写上下文**：`reelforge.save_context` 写 `bible` / `style` / `continuity`。
   - `bible` 必写「场景站位表」：空间锚点 + 各角色默认方位 + 道具锚点 + 180° 轴线与允许机位。
   - 每次写 `bible` 前**先读回现有内容**，把已有的人物与衣橱一并带上，避免被覆盖。
3. **建资产**：`reelforge.create_asset` 建角色/场景/道具；`costume` / `age` 是**变体类，必须带 `parent_id` 指向角色**（缺了会被拒绝）。
4. **拆分镜**：`reelforge.set_storyboard` 写分镜。分镜字段与硬约束见 `reelforge-story-pipeline`。
5. **跑阶段**：`reelforge.run_stage` 按 `llm → image → tts → video` 顺序跑。会烧钱的触发类工具走宿主的 `ask` 人工授权。
6. **合成**：`reelforge.assemble_chapter` 合成某章成片（带字幕 + 无字幕两版 + SRT）。
7. **回滚**：`reelforge.rollback` 支持单条 / 整批 / 按时间点三级回滚。

## 四、写作纪律（每一条都会造成静默错误）

- **参考占位符**：`__MINIMAX_H3_REF_N__`，**N 从 1 起**，编号必须与参考图装配顺序严格一致。
- **提示词改写最多 2 次尝试**，且**必须保留全部占位符**——丢一个占位符等于引用素材丢失，画风立刻漂。
- **参考图 ≤ 9、音视频 ≤ 3**（后端硬上限）。超限会**报错**，不要靠少绑几个素材硬凑。
- **角色名匹配必须规范化后精确相等**，不要用「包含」式匹配——「林岸」会命中「林岸生」，错挂音色还挤掉音频名额。
- **镜头时长 1–15 秒**；台词 **≤ 5.5 字/秒**；**每镜说话人 ≤ 2**。
- **只有说话的角色才引用音色**——不出声角色的 `voice_ref` 不提交。
- 分镜时长要按后端能力量化：总量守恒、落进允许时长集合，别先选完模型再祈祷分镜能用。

## 五、失败时怎么说

缺什么就说清楚缺什么、给什么替代，不要静默降质：

- 没有 ComfyUI / 没有 GPU → 说明只能走云端档，并说清代价。
- 音色推不出来 → 跳过该角色并**在对话里明说**，不要硬造一个烂音色。
- 参考素材超限 → 说清超出几张、建议解绑哪些。

## 六、专项技能

- `reelforge-story-pipeline` —— 小说 → 剧本 → 分镜
- `reelforge-image-prompt` —— 图 / 图生图提示词规范
- `reelforge-video-prompt` —— 视频提示词 + 参考标签规范
- `reelforge-voice-design` —— 音色设计规范
