# 四阶段与依赖语义（详细）

## 阶段表

| 阶段 | 产出 | 依赖 |
| --- | --- | --- |
| `llm` | 大纲、`bible` / `style`、分镜、prompt | 无 |
| `image` | 角色三视图、场景图、道具图、服装/年龄变体 | 无（但依赖 `llm` 的资产清单） |
| `tts` | 每个角色的 `voice_ref` | 依赖 `llm` 的人物圣经 |
| `video` | 分镜视频、成片 | **硬依赖 `image`**，**软依赖 `tts`** |

## 硬依赖 vs 软依赖

- **硬依赖**：缺了就不该开跑。`video` 缺 `image` 的参考图 → **直接报错**。
  理由：没有参考图出片，同一角色在不同镜头里就不是同一个人，一致性当场崩掉。
- **软依赖**：缺了能跑，但**必须说出来**。`video` 缺 `tts` → 出片没原生音轨，
  对话要么没声要么靠后期配音。**在对话里明确告知**，不要让用户拿到成片才发现。

## 顺序为什么不能乱

1. `llm` 定锚点（人物圣经 / 风格指南 / 分镜）。
2. `image` 按锚点出**资产参考图**（这些图就是后续每个镜头的参考素材来源）。
3. `tts` 按人物圣经里的声音描述设计音色。
4. `video` 用「资产参考图 + 音色 + 分镜」出片。

`llm` 与渲染阶段互斥：文本创作没定稿就开渲染，等于拿未定稿的分镜烧钱。

## 跑阶段的建议

- 一次只推进一个阶段，跑完看产物再进下一阶段。
- 触发类工具（`run_stage` / `regenerate_shot` / `assemble_chapter` / `rollback`）会烧钱或覆盖既有产物，
  宿主会走 `ask` 人工授权——不要试图绕过。
- 重跑只重跑失败的那几镜，不要整章重跑（重复计费）。
