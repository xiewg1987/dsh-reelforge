# ReelForge 设计稿（v4 · 桌面端右栏面板）

本目录是 ReelForge（DSH 桌面端右栏插件）的设计稿源文件。**全部画板按用户操作流程排序**，
文件名前缀、FigCraft 画布排布、方案文档 §10.6 的表格行序三者一致。

> **v4 重定基**：参照源从 `Toonflow-app` 换成 [`SwotAtmk/infinite-creation`](https://github.com/SwotAtmk/infinite-creation)（MIT）。
> 核心契约来自它的 `SKILL.md`——「不启动本项目，Agent 照此流程 + `skills/` 技能库，在任意环境实现同样的「小说 → 视频」」。
> ReelForge 就是这条用法②，宿主换成 DSH。

## 文件

- `??-RF-*.svg` —— **17 张**界面稿的可编辑源文件（UTF-8 无 BOM，首字符即 `<svg`）
- `??-RF-*.png` —— 对应的 2x 成图（1120×1800）
- `ARCH-*.svg` / `ARCH-*.png` —— 两张架构图源文件与 1x 成图（1200×700）
- `ReelForge-DSH-Plugin-UI.figcraft` —— 设计文件本体，文本层是**真实可编辑文本**（Noto Sans SC / Inter）
- `STYLE-SPEC.md` —— 出图规范（画布、栅格、颜色、字体、StageBar、硬性要求）
- `_v2-board-specs.md` —— 逐张画板的内容规格（v4）
- `_tools/check-svg.mjs` —— 几何校验器（尺寸 / 越界 / 禁用元素 / 颜色字体白名单）
- `_tools/check-inset.mjs` —— 贴边检测（卡片内元素压到卡片描边）
- `_tools/check-overlap.mjs` —— 文字遮挡检测（后画矩形盖住已画文字）
- `_tools/patch-stagebar.mjs` —— StageBar 步数改写（5 步 ↔ 6 步）
- `_tools/render-all.ps1` —— 批量校验 + headless Chrome 渲染，供目视复核

## v4 变更（相对 v3）

1. **前提级修正：「本地 vs 云端」不是两档能力，是同一批 kind 的两套 sourceFile**。
   v3 的 `03-RF-RunMode` 写成「本地 = 你的模型集 / 云端 = H3 系」，`04-RF-DeviceCheck` 的探测项也是按这个错的模型列的。
   v4 改为：云端 = 托管工作流（RunningHub / 在线 API / DSH 通道），与本地**同样支持** `t2i / i2i / r2v / tts / music`，
   差异在**跑在哪、计不计费、受什么约束**。
2. **`05-RF-Plan` 从「方案评分」改为「执行路径矩阵」**：决策轴是 **kind × 执行位置**；评分降级为辅助条。
3. **新增四页**：`06-RF-Stages`（四阶段勾选）、`07-RF-Context`（三栏上下文）、`12-RF-Skills`（技能）、`13-RF-Changelog`（变更日志与回滚）。
4. **产物单位从「一条 30s 短剧」改为「项目 → 章节 → 分镜 → 成片」**：首页加章节进度区，Intake 加拆章预览，Player/Deliver 改章节制。
5. **资产库 3 类 → 10 类**；服装/年龄作为**变体**挂在父资产下（parent_id），参考图优先级 `服装 > 年龄 > 原图`。
6. **`11-RF-Runs` 删除**：历史运行被右栏「日志」页吸收，不再单独出图。原 12–15 顺延为 14–17。
7. **降级矩阵 5 行 → 7 行**：新增「显存不足 → 静帧成片」「音色缺失 → 静音成片」。

## v3 变更（相对 v2）

1. **补上「运行」这一步**：v2 的 13 张把「本地还是云端」隐含在方案推荐里，5 步进度条（需求·方案·生成·分镜·交付）**静默跳过了一个真实的用户决策**。
2. **新增两页**：`03-RF-RunMode` + `04-RF-DeviceCheck`，落位在**需求之后、方案之前**。
3. **进度条 5 步 → 6 步**：需求 · 运行 · 方案 · 生成 · 分镜 · 交付。
4. **编号整体后移**：原 03→05、04→06 …… 13→15。
5. **架构图流水线 8 步 → 10 步**：插入「运行方式」「设备检查」两步。

## v2 变更（相对 v1）

1. **形态**：v1 是 380×920 的细长画板，那是手机竖屏比例，与「桌面端右栏面板」不符。v2 统一 **560×900**（比例 0.62），9:16 只作为**成片画幅**出现在 `10-RF-Player` 的画面区。
2. **体系**：v1 混用 380 / 420 / 480 三种尺寸；v2 起**尺寸完全一致**，架构图另用 1200×700。
3. **顺序**：v1 按「界面 / 架构」分类摆；v2 起按**用户操作流程**排序。

## 参考图版权

`references/` 下采集的真实参考图（花瓣 96 张 + Pinterest 16 张）**只作设计参考**，用于出图阶段比对构图与密度，
**不随产品分发**。来源 URL 记录在 `../references/manifest.json`，可按原 URL 重下。

v4 的界面稿里，镜头卡 / 资产卡 / 播放器画面的占位区**一律用实色矩形**表达，没有嵌入图片——
这是有意的：SVG 源文件、FigCraft 设计文件、PNG 成图三者**完全一致**，改一处三处同步，
不会出现「图上有、源文件里没有」的漂移。参考图需要时再手工贴进 FigCraft。
