# ReelForge 设计稿 v4 · 画板清单与逐张规格（按用户流程排序）

> 配套规范：`design/STYLE-SPEC.md`（v4）。**先读 STYLE-SPEC，再读本文件。**
> 基准画板：`design/01-RF-Workbench.svg`（基准，所有画板照它对齐）。
> 上游事实依据：`docs/ReelForge-设计方案.md`（以 `SwotAtmk/infinite-creation` 为参照源）。
>
> **v4 变更**：整份设计稿按 infinite-creation 重定基——
> 1. 界面稿 **15 → 17 张**：新增 `RF/Stages`（四阶段勾选）、`RF/Context`（三栏上下文）、
>    `RF/Skills`（技能管理）、`RF/Changelog`（变更日志与回滚）；原 `RF/Runs`（历史运行）被
>    「日志」页吸收，不再单独出图。
> 2. **前提级修正**：`RF/RunMode` 与 `RF/DeviceCheck` 的「本地 = 自己的模型集 / 云端 = H3 系」
>    是错的。真实契约是：**本地与云端跑的是同一批 kind 的两套 sourceFile**
>    （本地=你机器上的 ComfyUI 工作流；云端=RunningHub 等托管工作流）。
> 3. **`RF/Plan` 从「方案评分」改为「执行路径矩阵」**：评分降级为辅助，决策轴是
>    **kind（t2i/i2i/r2v/tts/music）× 执行位置（local/cloud）**。
> 4. 资产库 3 类 → **10 类**；上下文三键（bible/style/continuity）独立成页；
>    分镜新增「章内 idx / 时长量化 / 参考标签」。
> 5. 编号顺延：原 12–15 顺延为 14–17（`RF/Runs` 删除，其余不变）。

## 0. v4 为什么要重排

| 问题 | 处置 |
| --- | --- |
| v1：380×920 细长画板 = 手机竖屏比例，与桌面右栏面板形态不符 | 全部统一 **560×900**，一眼是桌面侧栏 |
| v1：画板尺寸 380/420/480 混用，不成体系 | **17 张界面稿尺寸完全一致**，架构图另用 1200×700 |
| v1：画板按「界面 / 架构」分类摆，没有流程顺序 | **按用户操作流程排序**：文件名带序号前缀、画布从左到右按序排、文档 §10.6 同序 |
| v2：5 步进度条**静默跳过了「运行方式」这个真实决策** | v3 补 `RF/RunMode` + `RF/DeviceCheck`，落在**需求之后、方案之前**；StageBar 扩为 6 步 |
| **v3：「本地 vs 云端」被画成「两套能力集」** | v4 修正为**同一批 kind 的两套 sourceFile**。云端不是「能力更强的一档」，而是「同一档能力换个地方跑」，按次计费 |
| **v3：产物单位是「一条 30s 短剧」** | v4 改为**项目 → 章节 → 分镜 → 成片**四层，不限时长。章节列表进首页、拆章预览进 Intake |
| **v3：没有「跑哪几个阶段」这个真实决策** | v4 补 `RF/Stages`：四阶段 `llm/image/tts/video` 可勾选、可按章勾选；**video 硬依赖 image、软依赖 tts** |
| **v3：一致性锚点无处安放** | v4 补 `RF/Context`：人物圣经（bible）+ 风格指南（style）+ 连续性记录（continuity）三栏 |
| **v3：技能与回滚是文档里的功能，界面上看不见** | v4 补 `RF/Skills` + `RF/Changelog` |

```

├─ Header   y   0 .. 60   底色 #171A20，底边线 y=59
│    logo 28×28 rx8 @x20,y16 · 标题 15px @x60,y31 · 副标 11px @x60,y49 · 状态胶囊右对齐到 540
├─ StageBar y  60 .. 110  底色 #12151B，底边线 y=109
│    6 步：需求 · 运行 · 方案 · 生成 · 分镜 · 交付   步点 cx=24/100/176/252/328/404，文字 x=cx+9（当前步 cx+10）
│    当前步 chip x=cx-12 y=74 w=56 h=22 rx6 底色 #16203A
│    右侧 "N / 6" text-anchor=end x=540
├─ Scroll   y 110 .. 830  底色 #0B0E14 —— 唯一滚动容器，内容左边界 20、右边界 540
│    （内容不得越过 y=826；右侧 x=548 放 3px 滚动条，y=126 起，高 120~180）
└─ Footer   y 830 .. 900  底色 #171A20，顶边线 y=830
     左侧文案两行（标签 11px @y862 / 主文案 12px @y884）· 右侧主按钮 104×32 rx8 右边缘 540
```

**内容区净宽 520**（x=20…540）。两列时：左列 x=20 w=254，右列 x=286 w=254（20+254+12+254=540）。
**通栏卡**：x=20 w=520。**卡内文字**：x=32。**右对齐**：x=528 或 540（通栏元素才用 540）。**居中**：x=280。
